fluxOS Windows drive C:\

This directory is the C: drive seen by Windows applications run with winrun.
Install applications in C:\Program Files, or copy portable applications here.
C:\WINDOWS contains compatibility configuration; builtin DLLs are provided
by winrun. Z: exposes the native fluxOS filesystem.

The registry is stored below WINDOWS/registry as typed value files in key
folders. It persists with /winapps when that directory is on persistent storage.
